# Roadmap (Planeamento)

## Fase 0 - Fundacao
- Definir dominio e termos de negocio.
- Fechar arquitetura e contratos principais.
- Criar bootstrap da API e estrutura de configuracao.

## Fase 1 - Primeiro fluxo funcional
- Coleta simples de dados por adapter mock.
- Persistencia basica em banco.
- Endpoints de leitura: health, lista de torres, detalhe de torre.

## Fase 2 - Integracoes reais
- Adapter SNMP generico.
- Primeiro fabricante real (ex.: Huawei).
- Normalizacao de eventos e severidades.

## Fase 3 - Operacao e escala
- Metricas e alertas operacionais.
- Endurecimento de erros e retries.
- Melhorias de performance para consultas historicas.

## Entregaveis tecnicos por fase
- Codigo
- Testes
- Documentacao
- Checklist operacional
